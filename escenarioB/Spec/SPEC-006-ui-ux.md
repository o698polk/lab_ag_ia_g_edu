# SPEC-006 — Interfaz de Usuario (UI/UX)

- Bootstrap 5.3, diseño moderno y limpio.
- Paleta configurable (CSS variables dinámicas).
- Modo claro/oscuro (localStorage + BD). Tema institucional: ver SPEC-010.
- Sidebar colapsable, navbar fija.
- Banner de impersonación fijo.
- Tablas: búsqueda, paginación, exportación.
- Formularios con validación dual.
- Toasts, loaders, modales de confirmación.
- Dashboard con métricas y accesos rápidos.
- Responsive (desktop, tablet, móvil).
- Fuentes: Inter / Poppins. Íconos: Bootstrap Icons.
